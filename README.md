## 👋 Hello, Python!

Welcome to **helloPython** — my personal Python learning lab.

This repository is where I document my journey of learning Python from the fundamentals and gradually using it for **data analysis, automation, APIs, ETL, and eventually data engineering**.

I'm not trying to build a collection of copied tutorial code.

I'm trying to build a habit:

> **Learn → Code → Experiment → Break → Fix → Build → Repeat.**

Some code here will be beginner-level. Some experiments will be messy. Some solutions will probably make me cringe six months from now.

That's intentional.

This repo is a **timeline of progress**, not a finished product.
